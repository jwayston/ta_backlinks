# Backlinks plugin for [The Archive](https://zettelkasten.de/the-archive/)

This plugin shows the backlinks of the current note in a separate window.

The plugin aims to tackle the challenge of understanding backlinked notes when notes' filenames are pure UIDs. The traditional file naming convention is supported however.

The description for the backlink is extracted primarily from the filename. If the filename is just a UID, it retrieves the first H1 header.
